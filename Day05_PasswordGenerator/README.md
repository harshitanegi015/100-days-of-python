# 🔐 Day 5 – Password Generator

> Part of my **100 Days of Python** journey 🚀

This project generates a secure, randomized password based on user input.

---

## 📌 Project Overview

The user specifies:
- Number of letters
- Number of symbols
- Number of numbers

The program then:
- Randomly selects characters
- Shuffles them for better security
- Outputs a final strong password

---

## 🧠 Concepts Practiced

- Python Lists
- For Loops
- `random` module
- `string` module
- List shuffling
- String joining
- User input handling
