# Day 03.1 - Treasure Island 🏝️

## 📌 Concepts Practiced
- if / elif / else statements
- Nested conditionals
- User input handling
- String methods (.lower())
- Logical decision flow

## 🚀 Project Description
A text-based 'choose-your-own-adventure' type game where the player makes decisions to find hidden treasure.

The user must:
- Choose the correct direction
- Make safe choices at the lake
- Pick the correct door

Wrong choices result in Game Over.

## 🧠 What I Learned
- How nested conditionals control program flow
- Importance of input formatting using `.lower()`
- Building simple interactive command-line games
